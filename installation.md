# **Installation**

1. Download the project files from the GitHub repository and extract the downloaded ZIP file.

2. In your terminal, navigate to the directory where the project files are located. For example:

   ```bash
   cd D:/CL-Project/
   ```

3. Install the toolkit:

    ```bash
    pip install .
    ```

4. Optional: Verify the package installation and view package information:

    ```bash
    pip show corpus-linguistics-toolkit-for-Chinese
    ```

5. Check whether the toolkit can be successfully imported:
    
    ```bash
    python -c "import toolkit; print('Toolkit imported successfully')"
    ```

1. in your terminal, go to the direction where you have the files downloaded, for example:
    ```
    cd D:\CL-Project
    ```
2. install the package
    ```
    pip install -e .
    ```
3. optional: show package information
    ```
    pip show corpus-linguistics-toolkit-for-Chinese
    ```
4. import the package
    ```
    python -c "import toolkit; print('Toolkit imported successfully')"
    ```
